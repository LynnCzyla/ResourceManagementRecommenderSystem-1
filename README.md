# ResourceManagementRecommenderSystem

A web-based Resource Management Recommender System that uses OCR and NLP to extract employee skills, certifications, and experience from resumes and training documents. The system helps Resource Managers efficiently assign qualified employees to projects based on project requirements and employee availability.

**Tech Stack:** React + Vite, Python, OCR (Tesseract), NLP, Supabase

> **Security & Access Control:** Branch-level permission checks across all recommendation and resource assignment endpoints are centralized in `checkBranchAccess()` within [`recommendationController.js`](file:///c:/xampp/htdocs/ResourceManagementRecommenderSystem/backend/controllers/recommendationController.js).
